## Core flow

Suspicious message → validation → cybersecurity detection → Amazon
Bedrock → risk fusion → risk/category/indicators/explanation/actions.

## AWS

Next.js → API Gateway → Lambda → Detection Engine + Bedrock → Risk
Fusion → DynamoDB. Amplify Hosting where appropriate.

Dark-first premium cybersecurity SaaS. CodeAnt and 21st.dev/React Bits
screenshots are visual references only. Use large typography, thin
borders, editorial spacing, smooth scroll/reveal and original animated
security visuals. Footer remains dark.

## Security

Input validation, rate limiting, prompt-injection defense, AI output
validation, least-privilege IAM, secret protection, safe errors, CORS
and minimal data retention.
