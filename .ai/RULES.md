# AI Coding Agent Rules

1.  Read `README.md`, all `docs/*.md`, and `.ai/MEMORY.md` before
    changes.
2.  Follow the implementation phases; do not jump ahead.
3.  Before the official build window, do not implement judged product
    functionality.
4.  Do not expand MVP scope without explicit approval.
5.  Treat supplied UI references as inspiration, never as assets/layouts
    to copy.
6.  Preserve the dark-first ScamShield visual direction and dark footer.
7.  Never hardcode secrets or expose AWS credentials.
8.  Validate all external input.
9.  Treat user messages and AI output as untrusted.
10. Use schema validation for AI output.
11. Use least-privilege IAM and intentional CORS/rate limiting.
12. Do not add AWS services without a real responsibility.
13. Run relevant tests after meaningful changes.
14. Never claim success without verification.
15. Never delete working functionality to fix an unrelated issue.
16. After each phase report changed files, tests, results, known issues
    and remaining work.
